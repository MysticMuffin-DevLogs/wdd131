Family Budget

Site Name

Family Budget: a simple, clear name that tells visitors right away the site is about practical budgeting for families. The house-and-dollar logo above will appear in the header of every page.

Possible domain: familybudget.org

Site Purpose

The site is a budgeting site for young families. It explains how to build a monthly budget, track weekly spending, and stay on top of bills, with simple tips for families with small children and a form to sign up for a free monthly budget template.

Scenarios

  • How do I start a budget when we have a new baby and money is tight?
  • What budget categories should a young family track?
  • How often should we check our spending: weekly or monthly?
  • Where can I get a free budget template to use with my spouse?

Typography

Fira Code 600: Headings

Used for the site name, page headings and card titles.

Fira Code 400: Body text. Used for paragraphs, navigation links, form labels and the footer. A clean monospace Google Font that matches the code-editor look used across my WDD 131 pages. I really like the colors of visual studio code and its typography so I wanted to kind of match it here.
